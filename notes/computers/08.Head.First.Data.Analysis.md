- 1. 分解数据：
数据分析引言
  - 1. 确定问题
    - 1. 询问客户，touch五个问题，确定目标
2. 帮客户思考：客户对自己的认知有可能是错的
3. 好的问题比答案更重要
  - 2. 分解问题
    - 1. 小问题化：可管理、可实操（类似OKR）
2. 比较因子：有效的比较是数据分析的核心
  - 3. 评估
    - 1. 比较：跟分解一样，评估分解组块的关键是比较
2. 假设并验证
  - 4. 决策
    - 1. 背景：包含与客户的讨论与假设
2. 解说：图表+解析
3. 建议：
  - 心智模型
    - 1. 心智模型：假设+观点 
2. 观点来自：上司、政府、媒体、自己
3. 多维思考：尝试其它心智模型解释数据
4. 观点<=>数据：当数据有违假设，就要回头重新思考
    - 管理未知
      - 1. 模型可能是错的，或残缺的，需考虑未知因素
2. 圈内是已知，圈外是未知：圈越大，代表知道的越多，则我知道的我不知道的一定也越多
3. 我知道半数广告打了水漂，但我不知是哪一半
4. 顾客只告诉你他们知道的事情，对于他们不知道的事情往往避而不谈
- 2 实验：
检验你的理论
  - 实证检验
    - 1. 摆脱对观察数据的无限依赖
2. 理清因果关系
3. 实证数据让你的分析更有说明力
  - 1. 数据只有相互比较才有意义
2. 观察 => 比较 => 规律
3. 观察研究法：图表更清晰，但维度选择很主观
  - 1. 用数字说话 => 用比较说话
2. 数字：解决模糊问题
3. 比较：解决标尺问题；老板需要知道业务是进步还是后退了，你只说数字，他没有感觉的
  - 1. AB Test，随机控制实验
2. 对照组：控制组，一切照旧；影响因子控制到只有一个
3. 当策略未在数据中充分体现，则需要实验检验
4. 并不是所有的事都能做对照实验，比如选举
  - 1. 拆分数据块，小数据块更具同质性
2. 混杂因素：绕不开 & 可能未知；各组间的差异
3. 时间、地域、经济、年龄、教育、职业、爱好
4. 随机采样：使隐性混杂因素同票同权，避免🍎 vs. 🍊
5. 随机列：EXCEl新建RAND()列 => 排序 => 分组
- 3. 最优化：
寻找最大值
  - 销售
- 4. 数据图形化：
图形让你更精明
- 5. 假设检验：
假设并非如此
  - 1. 请勿试图选出最合理的假设
2. 只需剔除无法证实的假设
- 6. 贝叶斯统计
  - 1. 预测未来
2. 不断利用新证据修正主观概率（信心）
  - 1. P(H) ⇒ 先验概率，简单随机抽样的比率
2. P(H|E) ⇒ 后验概率
3. P(E|H) ⇒ 条件似然，似然概率
4. P(E) ⇒ 证据E发生的概率，又称为归一化常量 ([链接](https://www.zhihu.com/question/51448623/answer/147298455))
  - 1. 先验比：PPR = P(H) / P(~H)；Prior Probability Ratio
2. 似然比：LR = P(E|H) / P(E|~H)；Likelihood Ratio ([链接](https://github.com/lixianmin/cloud/blob/master/writer/R/bayes.md))
    - 学校里60%的男生，40%的女生。男生总是穿长裤，女生则一半穿长裤一半穿裙子。
迎面走来一个穿长裤的学生（不幸你高度近视，看不清性别），你能推断是男生的概率多大吗？
    - 1. 贝叶斯是二值分类器，此处分男女
2. PPR=男生数/女生数=60/40
3. LR代表男女对证据项的响应或态度，LR=男生响应/女生响应=1/0.5
- 7. 主观概率：
信念数字化
  - 1. 避免用词模糊导致的交流偏差
2. 可以使用使用概率公式进一步推导
  - 0. 事件发生概率是0，表示证伪
1. 事件与证据是相互独立的关系
2. 小概率导致事件发生
3. 中概率导致事件发生
4. 大概率 导致事件发生
5. 百分百导致事件发生

- 13. 整理数据：
井然有序
- 1. 贝叶斯：预测未来；利用新证据优化主观概率
2. 标准差：波动率、稳定性、分歧程度
3. 因果倒置：自变量和应变量是否可能搞反了？
4. 比较法：产成结论，引导思考；AB测试
5. AB测试：验证假设；随机采样
6. 奥卡姆剃刀：当多个模型可解释实验时，选最简单的那一个；避免过拟合，避免连噪音都拟合
