- 04 安全
  - 1. XSS: Cross-Site Scripting(不敢叫CSS), 跨站脚本
2. CSRF: Cross-Site Request Forgery, 跨站请求伪造
  - 1. SOP: 同源策略, 站点隔离: DOM, cookie, fetch
2. 白名单 = CSP(meta, 三方资源) + CORS(header, 跨域请求)
3. postMessage: 跨域操作DOM, 类似windows消息
  - 1. cookie存键, session存值
2. cookie让http无状态化, 状态集中存储在session中

1. HttpOnly: 禁止js使用document.cookie, 防XSS
2. SameSite: 跨站访问是否可以带cookie, 防CSRF
3. Secure: 约束cookie仅用于https ([链接](https://time.geekbang.org/column/article/333272))
  - 1. jwt: 用于认证, 后端无状态化, 适合水平扩容
2. cookie和jwt都在request header中
  - 1. 公私钥均可加解密, 仅私钥可签名
2. web3中address是公钥的hash值, privateKey是私钥, mnemonic等价于私钥; 私钥可逆推公钥
- 05 http
  - 1. 持久链接: keep-alive(默认), 队头阻塞 → pipeline(废弃)
2.即时压缩: server不确定content-length → chunk transfer
3. 强制Host头: 多个虚拟机共用物理机的IP
4. 单域名6tcp + 基于CDN实现域名分片
  - 1. ip无状态 → tcp有状态 → http无状态
  - 1. 二进制(代替纯文本)分帧层(多路复用, 雪碧图失效)
2. 单域名单tcp: 规避tcp慢速启动
3. TLS挟持: chrome拒绝H2C, golang+TLS自动升H2
3. 头部压缩, 请求优先级 ([链接](https://time.geekbang.org/column/article/148546))
  - 1. 效率提升20%~60%, 50%网站支持http/2
2. grpc
3. server push: chrome在2020年废弃 ([链接](https://time.geekbang.org/column/article/324863))
  - 1. 连接id: 移动设备快速切网, 换ip不换连接
2. 快速握手: 0~1个RTT建链接
3. TLS必选
4. 流量控制, 可靠传输, 多路复用
- 6 缓存
  - 1. 方便了市民, 方便了黑客
2. Cache-Control: max-age=3600; expires=<date> (弃用)
 set-cookie: Max-Age=3600; Expires=<date> (弃用)
  - 1. 身份认证: 免登录
