- 0. 寄语
  - 1. 主动是被动无法生效时的被动选择
2. 无知之错: 可以理解; 读书
3. 无能之错: 不可原谅; 清单
4. 清单=简洁+有效(实测)
5. Atul Gawande 阿图.葛文德《最好的告别》
  - 1. 任务清单: 追踪, 防丢三落四(被动); teambition
2. 步骤清单: 程序, 防偷工减料(主动); 纪律
3. 诊断清单: 冷静, 现象->归因->方案; 投资, 可卡因头脑
4. 脑图: 思维模型, 备忘
  - 1. 清单: 紧急问题. 例行步骤, 忙中有错
2.会诊: 复杂问题. 抛出问题, 专家沟通, 权力下放, 进度追踪3. 激活现象: 自我介绍(姓名+职务); 心理学表明不知道彼此姓名的人往往不能很好地合作.
  - 1. 知识日益复杂, 远超个人正确, 稳定发挥其能力的范围
2. 每一步都有多个选择, 都有风险
- 1. 人人都会犯错
  - 1. 重症监护的病人占比22%，生存率86%
2. 医生: 1900年, 高中毕业读1年; 2000年, 4年本科+3~7年住院医生培训; 现在, 再加1~3年专业进修
3. 通常35岁才能开始独立执业
  - 1. 分工再分工: 解决之道, 以医为例
2. 超级专家: 知道更多重要细节+学会了如何掌控特定工作的复杂性
3. 挑战: 专业分工不足以解决问题, 超级专家也会犯错
- 2. 关键点比大而全重要
  - 1. 困难一: 记忆或注意力谬误, 重压下忽略例行事项
2. 困难二: 麻痹大意, 故意跳过一些明明记得的步骤
  - 1. 4项重要体征: 体温, 心率, 血压, 呼吸频率
2. 调查表明, 在无清单帮助时, 1/3的重症操作不规范
3. 仅仅要求医护为日常操作编写清单, 就可显著提高绩效水平
4. 18个月,参与行动的医院, 节约了1.75亿美元
  - 1. 冒犯了他们的尊严
2. 本来已经繁重的工作雪上加霜
3. 把文案工作忘掉吧, 我们真正应该关心的是病人
- 3. 团队犯错的概率比单个人要小
  - 1. 贝叶斯概率: 一个人免不了犯错, 一群人犯错的可能性会变得小一些; 多次/人检查是有用的
  - 1. 简单问题: 烘焙; 有明确解决方法; 一旦掌握, 容易成功
2. 复杂问题(complicated, manager): 发射火箭; 无直接解决方案, 但可分解为一系列简单问题; 可重复; 对应COT拆解而非推理
3. 极端复杂(complex, leader): 抚养孩子, 建造大楼; 不可预测, 不可重复；处理涌现
    - 1. 简单问题: 集中注意力, 避免低级错误
2.复杂问题: 分解为简单问题, 极致分工
3. 极端复杂: 发现问题,充分沟通,权力下放,进度跟踪
    - 1. 专家组: 不同领域的专家, 作为团队而不是个人, 充分讨论, 可以发现和避免严重错误
2. 相信沟通的力量, 而不依赖个人智慧
3. Clash Detective: 发现施工冲突
4. Project Center: 反馈问题, 讨论解决
5. 过去十年, 建筑领域最大的进展, 就是对进程跟踪和沟通过程不断完善
6. 清单有效: 现今的建筑比历史任何时期的都要复杂, 施工时间却比几十年前缩短了1/3
- 4. 权力下放: 清单由谁来主宰
  - 1. 任务清单 (跟踪): teambition, 中央集权
2. 步骤清单 (紧急): 例行程序, wiki; 中央集权
3. 授权清单 (复杂): 高层不直接决策, 督促大家积极参与讨论
  - 1. 新奥尔良风灾: 无政府状态, 奥威尔式官僚
2. 沃尔玛高层把工作重点放在设定目标, 监控进度以及保持和一线员工及政府机构的联络上. 也就是说, 在应对这一极端复杂的危机时, 他们没有发布具体的指令
3. 范海伦乐队: 使用巧克力豆作为保障演唱会安全的试金石
4. 菜谱: 纪律, 高质量服务, 连锁店
5. 平衡点: 自由与纪律; 个人发挥与标准程序; 专业技能与集体协作
- 5. 简单至上: 清单要素的选择机制
  - 1. 没有清单可涵盖所有情况, 冗长而含糊的清单无法高效&安全的执行
2. 激励的缺点: 难以测量, 医生自己报告, 无法保障准确
3. 会诊清单: 自我介绍(姓名+职务), 激活团队
  - 1. 外科手术的并发症, 有3%~17%, 至少一半是可以避免的
2. 医生往往不把护士当作团队的一份子
3. 团队简报: 就重要事项进行交流, 沟通意外; 手术室很忙乱, 距离成为真正的团队还很远
4. 极致分工副作用: 事不关己, 高高挂起. 这是阻碍团队有效合作的主要阻力
5. 医护人员应当在手术前就手术的具体情况进行交流, 至少要在手术开始前花1分钟时间进行简短讨论, 这是一个促进团队合作的好方法.
6. 医护人员在手术开始之前应该熟知彼此的姓名.
  - 1. 6场景: 饭前, 便后, 洗澡, 烹饪, 喂食, 擦拭婴儿. 
2. 腹泻降低52%, 肺炎降低48%, 疱疹降低35%. 
3. 香皂不仅仅是香皂, 它还改变了人们的行为
4. 方法: 充分打湿, 均匀涂抹, 长时间搓手, 冲洗干净
- 6. 人为根本: 清单的应急反应机制
  - 1. 清单: 防止人们犯错的科学
2. 减少虚警: 中位数滤波器(不是均值滤波器)
3. 程序= 代码 or 清单
  - 1. 哈得孙河上的迫降奇迹
2. 解决问题的主角是人, 而不是清单
3. 飞行+手术清单的共同点: 重复+紧急; 大促演练很重要
4. 相信程序, 不要相信直觉; 清单也是一种程序
5. 不要让事故成为遗憾, 而要让事故成为: 程序=代码+清单
6. 复盘与新标准, 并不意味着人们会立即改变行为, 原因是新知识并没有被系统的转化为简单, 实用的操作方法
  - 1. 设置清晰的检查点, 如警灯亮起, 发动机停车
2. 二选一: 操作-确认, 或边读边做
3. 清单太长人们会偷工减料; 5~9项, (5+9)/2=7, 美国电话号码
4. 精练, 准确, 使用专业术语
5. 版式: 长度不要超过一页, 大小写字母结合, 方便阅读
6. 经过实践检验, 不断改进
- 7. 持续改善: 保持清单的自我进化能力
  - 1. 简洁vs.有效: 删减过多,许多重要步骤会无法检查; 保留太多, 清单又会冗长难用. 
2. 持续改善, 才能让清单始终确保安全, 正确和稳定
3. 在航空业, 负责启动检查程序的是不把杆的飞行员, 在手术室, 则是护士---分权, 让更多人的担责, 分享提出质疑的权利
4. 手术室: 有些话可能碍于情面不太好说出口
5. 不要斥责, 强迫只会引起更大的反弹, 抵触情绪
  - 1. 8家试点医院: 术后严重并发症下降了36%, 术后死亡率下降了47%, 感染率几乎下降了一半
2. 是否会是巧合? 比如清单投入后, 急救手术数量变少了?
3. 是否会是霍桑效应? 因为有人观察, 导致团队变谨慎?
4. 沟通质量的改善是关键
5. 93%回答肯定: 如果你自己被手术, 是否希望手术团队使用清单?
- 8. 清单, 让世界更简单
  - 1. 人人都会犯错, 列出它们, 并设置相应的检查项, 普通智力的人也可以避免重蹈覆辙 
2. 目标不是给检查项打勾, 而是培养合作和纪律
  - 1. 可卡因头脑: 会干扰理性思维, 头脑发热, 轻易看到支持自己初始判断的证据, 而对那些负面因素视而不见; 被销售洗脑后
2. 帕巴里: 投资清单(冷静)
3. 把伯克希尔-哈撤韦公司的所有投资决策都分析了一遍, 把所有关于巴菲特的书籍都读了一遍
4. 投资是一项高风险行业, 有些错误不可避免, 但有些本可以
5. 牛市里你抵挡不住诱惑, 便开始投机取巧; 熊市里人心惶惶, 你会不由自主的高估潜在的风险
6. 芒格+巴菲特对互联网泡沫一清二楚, 却还是忽略了经济周期的大幅波动对这家公司收的影响
  - 1. 库克: 三日清单
2. 在一张财务报表上作假并不难, 但要用各类财务报表把谎话给编圆了就没那么容易了
3. 每50次检查可能会有49次一无所获, 但就是这一次发现却能让你避免重大损失
4. 在没有增长专业技能的情况下, 他们却提高自己的业务水平
5. 在变化越来越快的商业环境里, 清单让众多商业人士具有了一个额外的优势, 那就是效率 --- 这与直觉相反
6. 整体上来看, 清单让他们能在较短的时间里对更多的投资机会进行评估, 而整体效率的提高不是一星半点
