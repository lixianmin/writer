- 0. 寄语
  - 1. vertex必须完成MVP
2. ZWrite Off ⇔ 大Queue
3. _LightColor0.rgb*_Color.rgb*_Brightness=光*色*亮
4. Common.hlsl中有URP的各种预置规则
5. ZWrite控制深度缓冲, ColorMask控制颜色缓冲
  - 1. 矢量=方向+模; 不受平移影响, 因此是half3 (w=0)
2. N·L点积=投影长度=夹角余弦
3. 点的w=1, 矢量的w=0; 顶点投影除以w以齐次化; TBN矩阵w
4. TRS矩阵顺序固定: 先S后R再T
5. TBN: turbulent矩阵, TBN是三列的顺序
5. M左手坐标系, V右手
  - 1. N·L: 灯光检测
2. N·V: 边缘检测
- 1. 光照
  - 1. 色香味俱全: 颜色, 方向, 位置, 衰减, 强度 
2. 平行光: 有颜色, 无方向, 无位置, 无衰减, 强度不变
3. 点光源: 
4. 聚光灯:
  - 1. Albedo: 纹素颜色, if金属则指反照率. 与diffuse很像, 但包含全部光照信息, 且不会有diffuse的阴影或裂纹
2. Metallic: 金属度, 0=电介质, 1=金属; 金属没有diffuse
3. Smoothness: 光滑度, 影响反射 ([链接](https://learnopengl-cn.github.io/07%20PBR/01%20Theory/))
  - 1. Tags {"LightMode"= "ForwardBase"} 给CS的
2. #pragma multi_compile_fwdbase保证光照变量可被正确赋值
3. base pass: (最重要的)平行光, 逐pixel; _WorldSpaceColor0方向, _LightColor0颜色 
4. additional pass: 其它光, 逐vertex或逐pixel; 需开Blend模式
  - 1. diffuse=max(0, N·L), 核心NL, 视角无关, max干掉背面
2. specular=pow(max(0, N·H), _Gloss); H=nomalize(L+V); 核心NH, 视角相关, H控制光斑位置(与light和ey有关), _Gloss控制光斑大小
- 3 纹理
  - 1. 颜色: albedo或diffuse贴图
2. Bump(凹凸): 法线, 高度图
3. Mask(遮罩): 代替常量, RGBA存光强度, Scale, Gloss等, Dot2; ColorMask A
4. Ramp(渐变): 卡通渲染
5. 衰减: _LightTexture0 (_LightTextureB0之cookie), 速度快, 效果可
  - 1. TRANSFORM_TEX()只用于vert中, TEX➞首参texcoord
2. tex2D()只用于frag中, 2D➞首参sampler2D
- 2. 效果
  - ramp纹理
  - 1. Rim = (1-saturate(N·V))^Width
2. 边缘: rim=1 - saturate(N·V+_RimWidth) 控制边缘宽度
3. 高光: rimMask=pow(rim, _RimPower) 控制衰减速度
4. saturate(rimMask*NL) 检测是否朝向灯光
5. rim效果属于Emission
  - 1. Schlick = _R + (1-_R)*(1-N·V))^5
2. _R是基础反射率, 按金属度插值: R = lerp(R, color.rgb, metallic)
3. 建议自定义Pow5函数替换pow(xx, 5)以降低开销

4. 插值光照与反射: lerp(diffuse, reflect, saturate(fresnel))
5. 叠加光照与反射: diffuse+reflect*saturate(fresnel) 模拟边缘光照 ([链接](https://zhuanlan.zhihu.com/p/375746359))
