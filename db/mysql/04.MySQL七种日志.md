- redo log
  - 1. 原地复活, crash safe
2. WAL, Buffer Pool, fixed size
3. InnoDB引擎实现
  - innodb_flush_log_at_trx_commit
    - 0. 只写buffer
1. 每commit都fsync
2. 只写page cache，每秒fsync
- undo log
  - 1. 时光回溯
2. 逻辑日志
- binlog
  - 1. 影分身
2. MySQL服务器层实现
  - sync_binlog
    - 1. 直写page cache
2. 值为N (0, 1, 2...)表示每N次事务fsync一次
- relay log
  - 1. relay线程接收binlog写入本地，SQL线程异步解析为SQL命令
- general query log
  - 1. 排错时临时开启
2. 记录所有用户操作
3. show variables like 'general_log%';
4. SET GLOBAL general_log=on;
- slow query log
  - 1. 默认关闭
2. 记录超时查询，辅助调优
3. SHOW VARIABLES LIKE 'slow_query%';
4. SET GLOBAL slow_query_log=ON;
5. SHOW VARIABLES LIKE 'long_query_time';
- error log
  - 1. 默认开启
2. 记录MySQL启停时间以及诊断和出错信息
3. SHOW VARIABLES LIKE 'log_error';
