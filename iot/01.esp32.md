

#### 1 basics

1. [wokwi](https://wokwi.com/projects/new/esp32-s3) 中元件的VCC/GND引脚，通常可不接，不影响测试；但[cirkit](https://app.cirkitdesigner.com/project/48426437-876a-43db-94a0-b0ab0fa298ed) 中元件的VCC/GND需要接全
2. 上拉电阻 vs. 下拉电阻：
   1. 断开时电流及小，U=IR，因此压降极小，peer的电压与电阻连的一端的电压是一样的
   2. 闭合时电阻分压，电压决定于peer连的时VCC/GND
   3. 上拉电阻: 接VCC，断开时压降极小，peer是高电平
   4. 下拉电阻: 接GND，断开时压降极小，peer是低电平
3. 分压电阻 vs. 限流电阻，只是关注点不一样，结构上都是串联
4. ΔV = I x R ，欧姆定律算的是压降，类似于这个两座山之间的高度差

##### 05 LDR 光敏电阻

1. 自带电阻，因此初始化为 `pinMode(ldr_pin, INPUT);`
2. A0引脚analog，与D0通常2选1
3. D0引脚digital，暗时输出高电平，配合NPN做小夜灯
4. 可以直接读成整数: `int lux = analogReadLdrLux(ldr_pin);`

```c++
float analogReadLdrLux(int pin) {
  /// ESP32 ADC 分辨率为 12 位 (0 - 4095)，电压为 3.3V
  int analogValue = analogRead(pin);

  // 1. 将 0-4095 映射为真实电压 (0V - 3.3V)
  float voltage = analogValue / 4095.0 * 3.3;

  // 2. 根据分压原理计算 LDR 当前阻值 (假设模块上拉电阻为 10kΩ)
  // 当光照增强时，analogValue 变小，voltage 变小，计算出的 resistance 也随之变小
  float resistance = 10000.0 * voltage / (3.3 - voltage);

  // 3. 计算照度 Lux (根据 LDR 光电特性曲线)
  const float GAMMA = 0.7;
  const float RL10 = 50;
  float lux = pow(RL10 * 1e3 * pow(10, GAMMA) / resistance, (1 / GAMMA));

  return lux;
}
```



##### 06 NPN 三极管 (高通: P在中间)

1. 如果说 Button 是物理开关，则 NPN 就是电子开关
2. NPN与NMOS是等价的，P在中间，**高通 (高压导通)**；PNP与PMOS是等价的
   1. NPN是三极管BCE的顺序，也是NMOS中GDS的顺序
   2. B是Base，如 电流=0，则CE不通
   3. G是Gate，G与DS是绝缘的，NMOS的VGS > VGS(th)，则DS通电
3. 三极管便宜，是电流控制的；MOS管可以PWM，是电压控制的
4. BJT的Base前面接电阻，是为了限制静态电流过大；NMOS的Gate前面接电阻，是为了限制开关的动态充放电流太大；
